# Project Context

This project is a personal portfolio built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Goals
- Build a modern, clean, premium-looking portfolio
- Keep code modular and maintainable
- Prioritize responsive design
- Use smooth animations only when they improve UX
- Keep accessibility in mind

## Coding Rules
- Use TypeScript
- Use functional React components
- Prefer server components unless client components are necessary
- Keep components small and reusable
- Avoid overengineering
- Use clear naming
- Do not add libraries unless necessary
- Respect existing project structure

## UI Rules
- Clean and modern layout
- Good spacing and visual hierarchy
- Mobile-first
- Avoid clutter
- Animations should be subtle and purposeful

## How to Respond
- Explain what you are doing before major changes
- Teach step by step when requested
- When I say “just do it”, return concise output
- When fixing bugs, first identify likely cause, then propose the fix
- Do not rewrite unrelated code
